## [0.1.0] - 2026-11-09

First public release.

### Added

- A pixel art pet on your desktop that grows with your GitHub activity: PRs, reviews, merges, issues and commits, only in the repos you pick. Four stages, eight creature lines to collect, 28 trophies, a share card, vacation mode and an optional backup to a private repo in your own account.
- Installers for macOS (`.dmg`, ad-hoc signed), Windows (`.exe`) and Linux (`.AppImage`, `.deb`), built by a release workflow.
- Updates: Windows and Linux (AppImage) download and install a new version on their own; the other builds tell you that one is out. It is a row in Settings and an item in the menu, never a notification.
- Windows and Linux support: tray icon, a native tray menu on Linux, window title bars, and _Open at login_ on both.
- MIT license, contributing guide, security policy and issue templates.
